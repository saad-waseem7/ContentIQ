# ContentIQ

Personalized AI content coach — ingests a creator's posts and performance metrics, learns what over-performs relative to their own baseline, and generates grounded content recommendations.

Build phase: MVP on synthetic data, Week 1-2 of a 12-week build.

## Stack
- FastAPI + PostgreSQL + pgvector
- MLflow (model tracking)
- Alembic (migrations)
- Docker Compose

## Local setup

Prerequisites: Docker Desktop, Git.
